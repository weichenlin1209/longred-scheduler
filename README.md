# README
這是一隻可以自動編排驗歌順序的程式，因為只有吉他社的人要用所以寫的很隨便。如果你覺得不喜歡，**歡迎你一起來寫**。

## 網站版
直接用瀏覽器開啟 `index.html`，上傳表單回覆匯出的 CSV，依各日期填入驗歌地點後按「產生排程」即可。日期會從 CSV 的「總驗時間」欄位標題自動讀取，並與地點合併顯示在結果欄名（例如 `09/20（社辦）`）。每個日期時段固定有上、中、下三個位置，可拖曳歌曲定位或交換；若移至未填可參加的時段會顯示提醒，下載的 `result.csv` 會包含手動調整後的位置。

網站版完全在瀏覽器中處理資料，不會上傳 CSV。公開使用時，將 `index.html`、`app.js`、`scheduler.js` 與 `styles.css` 一起部署到任何靜態網站主機即可。

## 使用教學
打開表單回覆的試算表，點擊 `檔案` >> `下載` >> `.csv`。下載之後把檔案拉到跟這個程式同一個資料夾裡，並把檔名改成 `data.csv`。接下來根據不同作業系統會有不同的作法，分別用 `Linux`、`MacOS`、`Windows`講解。

總之，先把專案 clone 下來。  

### Linux
打開`bash`，cd 到你目前資料夾。輸入：  

```
./execute.sh schedule.c  
```

就會看到 `result.csv` 出現在資料夾裡面
